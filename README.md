# ⛏️ Гномы и Глубины

Single-player **Idle Roguelite Auto Battler** для браузера. Отряд гномов спускается в
глубины подземелья: сражается сам (auto battler), собирает экипировку, открывает
синергии и умирает — чтобы вернуться сильнее через Наследие. Один забег —
8–12 минут.

## Возможности

- **Детерминированные бои** — весь бой просчитывается заранее на собственном RNG
  (`mulberry32`, seed забега); воспроизводимость: один seed → один и тот же лог.
  Просмотр боя по событиям со скоростями 1×/2×/4× и кнопкой «Пропустить».
- **Отряд гномов** — 5 ролей (Страж, Воин, Стрелок, Маг, Жрец), позиции
  (авангард / середина / тыл) с бонусами слота, статусы (яд, горение, оглушение).
- **Синергии** — комбо от тегов и состава отряда (`src/lib/game/data/synergies.ts`).
- **Экипировка** — оружие / броня / амулет / руна, 4 редкости, стадии 1–3.
- **Карта забега** — узлы: бой, элита, босс, кузня, торговец, событие, отдых;
  ветвление маршрута.
- **Экономика** — золото, лут после боёв, магазин, кузня (улучшение предметов).
- **Мета-прогресс «Наследие»** — очки за забеги, разблок: слоты экипировки (2→4),
  размер отряда (1→3), автоповтор, автобой, автоэкипировка.
- **Idle-доход** — оффлайн-бонус за время между сессиями.
- **Сохранение** — всё состояние в `localStorage`, без сервера и аккаунтов.

## Технологии

- [Next.js](https://nextjs.org) (App Router) + React 19 + TypeScript
- Tailwind CSS + shadcn/ui, иконки `lucide-react`
- Никаких игровых движков — чистый TS: логика не зависит от рендера
- Звук — WebAudio-синтез (`src/lib/game/sfx.ts`), без аудиофайлов

## Локальный запуск

```bash
bun install
bun run dev      # разработка → http://localhost:3000
bun run build    # production-сборка (она же — проверка типов)
```

## Структура

```
src/
  app/
    layout.tsx            # шрифты (next/font/local), тема, метаданные
    page.tsx              # входная точка → <GameRoot/>
    actions.ts            # server actions
  components/game/
    GameRoot.tsx          # маршрутизация экранов по состоянию игры
    MenuScreen.tsx        # меню, Наследие, старт забега
    MapScreen.tsx         # карта забега, инвентарь («Рюкзак»)
    BattleScreen.tsx      # бой: воспроизведение лога событий
    OtherScreens.tsx      # кузня, торговец, событие, отдых
    EndScreen.tsx         # победа / поражение, награды Наследия
    bits.tsx              # мелкие общие компоненты (HpBar и др.)
  lib/game/
    types.ts              # контракты данных — единственный источник истины
    rng.ts                # mulberry32 — детерминизм забега
    store.tsx             # React-стор, сохранение в localStorage
    sfx.ts                # звуки на WebAudio
    data/                 # контент: гномы, враги, предметы, события, синергии
    logic/
      battle.ts           # симуляция боя → лог событий BattleEvent
      run.ts              # генерация карты, узлы, награды
      stats.ts            # расчёт статов гнома из экипировки и синергий
tools/
  make_runic_font.py      # генератор шрифта заголовков (чистый Python, TTF)
public/fonts/             # runic-mine.ttf (400) / runic-mine-bold.ttf (700)
```

## Шрифт заголовков (DeepGlyph)

Заголовки набраны кастомным руническим шрифтом, сгенерированным по спеку
**DeepGlyph**: сетка 24×32, ключи T=2 / M=16 / B=30, L=2 / C=12 / R=22,
перекладины с наклоном («горизонталей нет»), Ё-точки на верхней строке сетки.
Набор — 160 глифов: латиница, кириллица А–Я, цифры, пунктуация (unicase).

Пересборка шрифта после правки геометрии:

```bash
python3 tools/make_runic_font.py
```

Скрипт пишет оба начертания в `public/fonts/` и прогоняет встроенный валидатор
TTF (таблицы, контрольные суммы, cmap). Геометрия задаётся в `tools/make_runic_font.py`
в словаре `D`; правки файла шрифта руками не нужны. Подключение —
`next/font/local` в `src/app/layout.tsx`, Tailwind-токен `font-runic`.

## Сохранения и сброс

Прогресс хранится в `localStorage` браузера. Полный сброс — сброс данных сайта
для страницы в инструментах разработчика браузера.

## Известные ограничения

- Шаблонные shadcn-компоненты (`chart`, `calendar`, `sidebar`, `resizable`)
  содержат ошибки типов и в игре не используются — на сборку не влияют
  (проверка идёт через `bun run build`).
- Первый рендер меню может задерживаться на чтение `localStorage`.
